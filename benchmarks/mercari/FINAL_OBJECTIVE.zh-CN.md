# 直接用最终比赛损失训练融合

[English](FINAL_OBJECTIVE.md) · [完整结果](final-objective-results.json) · [上一轮融合对照](FUSION_STRATEGIES.zh-CN.md)

## 最终目标是什么

Mercari 使用 RMSLE，越低越好。设 `y = log1p(真实价格)`，`z` 是最终融合的
对数预测，提交价格采用 `expm1(max(z, 0))`，则：

```text
RMSLE = sqrt(mean((max(z, 0) - y)^2))
```

已有全局／条件线性模型已经优化平方 RMSLE 加声明的正则。上一轮 MLP 优化的是
标准化对数价格的 MSE 加 sklearn L2，并不是原始价格 MSE。不考虑截断和正则时，
它与平方 RMSLE 只差一个正常数倍率。**开平方与不开平方的无正则最优解相同**，
不能仅靠换一个损失名称就预期统计目标变得更好。在根号外保持同样大小的正则项，
还会改变正则相对强度；本轮细化时排除了这个混杂。

已有三个 MLP 在 selection／审计上都没有负的对数预测，审计最小值约 1.08–1.18，
所以保存预测上的截断本来就没有生效。真正值得测试的是额外优化是否有用，
以及对**最终平均预测**训练是否优于对每个成员独立训练。

## 三种受控损失

所有细化使用相同初值、同一全窗口 L-BFGS-B 优化器，保留 32／16 两个 ReLU
隐藏层、线性输出、仅训练窗口拟合的标准化／标签缩放／品类编码。72 列底层
预测被冻结，不重训文本专家。

| 损失 | 实际优化式 | 检验什么 |
| --- | --- | --- |
| `log_mse` | `mean((z-y)^2)` | 控制更换优化器、增加训练步骤的影响 |
| `squared_rmsle` | `mean((max(z,0)-y)^2)` | 精确处理最终截断，保持与指标单调等价 |
| `rmsle` | `sqrt(mean((max(z,0)-y)^2))` | 包含根号的完整全局比赛指标 |

每种损失测试三种应用方式：

1. **单模型：** 分别细化 42、43、44 三个种子；预先指定 42 为单模型主对照，
   其他两个只帮助检查稳定性。
2. **独立优化再平均：** 三个模型各自优化损失，再平均它们的对数预测。
3. **最终平均输出的联合优化：** 从同一组三个初值出发，对平均预测反向传播，
   同时修改三个成员的融合网络参数。这里只有一组三成员初始化。

联合优化的是 `L(mean(z42,z43,z44), y)`，不是三个成员损失的平均。必须在平均后
只截断一次。某个成员独立分数可能变差，但最终输出仍改善，因此不按成员的
独立分数将其提前删除。

RMSLE 对最终对数预测的解析梯度为：

```text
dL/dz[i] = (max(z[i],0)-y[i]) * I(z[i]>0) / (n * RMSLE)
```

再沿平均操作（乘 1／成员数）、各成员的标签缩放及所有网络权重反向传播。
RMSLE 为零时选零次梯度；截断边界也选零。方向导数数值差分覆盖了单、双、
三成员及全部三种损失。

每次求值的分母都覆盖**完整的融合训练窗口**。把各小批次 RMSLE 求平均是另一个
目标。训练直接在对数空间计算，不必显式 `expm1`，可避免不必要的数值溢出。

## 实验流程与成本口径

沿用原数据和 72 列输入清单；selection 内的分组训练／调优／检查分别为
44,477／14,825／14,824 行。底层候选与这些窗口在历史实验中已被查看，本轮仍是
复用数据上的条件实验。

- 三个 Adam 初值只拟合融合训练标签，并用原分组调优窗口早停。各损失共享同一批
  初值。完整 selection 重训时，用已经冻结的轮数重建初值。
- 细化最多 **20 次全窗口 L-BFGS-B 迭代**，连续 6 次没有至少 1e-6 调优 RMSLE
  改善就停止。第零步也是合法检查点；无收益时保留原始初值。
- 细化阶段**不额外添加 L2**。共享初值、迭代预算、调优早停提供约束。
  全局／条件线性控制组保留原来的正则，报告单独标明。
- 完整 selection 的细化使用冻结的迭代预算，不再早停。优化器可能提前收敛；
  请求／实际迭代数、函数求值次数和退出原因都会保存。不按是否达到收敛判据淘汰候选。
- 全部 21 个输出都会保存；13 个预先指定的方案参加策略检查。种子 43／44 的
  单模型只用于稳定性，不增加事后挑最好种子的机会。差距不超过 1e-5 时优先
  保留列表中更早／更简单的方案。13 项为全局／条件线性、初值单模型／平均，
  三种种子 42 细化、三种独立平均、三种联合平均。
- 所有完整重训和选择都先冻结，再读取审计标签。最终晋级要求在策略检查和完整
  selection 上都比此前冻结的线性输出好至少 1e-5。这个参考曾拟合 selection
  权重，其检查分数不是独立测试；原文件保持不变。本命令不提交 Kaggle。

共享初值训练只计算一次；细化时间是额外成本。求平均的包装器自己不拟合，
但依赖三个训练过的子模型，推理时间包含它们。包装器训练时间为零，不代表整套
模型不需要训练成本。

## 实测结果

全部 21 个冻结输出使用同一份 148,254 行复用审计数据。全局／条件线性精确
重现上一轮 **0.380609／0.380704**，三个初始 MLP 及其平均在 selection／审计
上的预测也逐位一致。本轮没有重训底层专家。

| --- | ---: | ---: | ---: | ---: |
| 原始三个 MLP 平均 | 0.387656 | 0.379682 | 0.000 | 0.962 |
| 独立对数 MSE，再平均 | 0.386845 | 0.379348 | 3.863 | 0.897 |
| 独立平方 RMSLE，再平均 | 0.386853 | 0.379345 | 3.536 | 0.950 |
| 独立 RMSLE，再平均 | 0.386846 | 0.379336 | 3.687 | 0.944 |
| 最终均值联合对数 MSE | 0.386984 | 0.379354 | 3.651 | 0.933 |
| 最终均值联合平方 RMSLE | 0.386906 | 0.379354 | 4.153 | 0.968 |
| 最终均值联合 RMSLE | 0.386936 | 0.379333 | 3.597 | 0.931 |

三个种子的训练及完整 selection 重训共用 **21.048 秒**，只计算一次。
额外时间包含调优阶段和完整重训阶段的细化。推理覆盖 **222,380 行**、重复三次、
使用两个 CPU 线程，包含全部所需成员、标准化和品类编码；排除缓存底层预测及
原始文本处理。JSON 保留全部样本、最大值和标准差。这是一次实验的观测，不能
据此声称新损失带来了推理加速。

**联合 RMSLE 的审计点估计最低：0.379333068**，旧三模型平均为 **0.379682351**，
相对降低 **0.092%**。但同优化器的对数 MSE 控制组已经达到独立平均
**0.379348195**、联合 **0.379353638**。联合方式中，加入精确根号后的额外差值仅
**-0.000020570**，配对区间
**[-0.000052786，+0.000006837]** 跨零；单模型、独立平均的
根号专属区间也跨零。因此，本次支持额外优化有用，尚不能证明单独更换根号
形式有可靠优势。

联合 RMSLE 相对“独立 RMSLE 再平均”的差值只有 **-0.000002788**，
区间 **[-0.000033160，+0.000026056]**。联合训练功能有效，
但不能据此认定它在本问题上稳定优于独立细化。

| 单模型损失 | 种子 42 审计 | 三种子算术平均 | 标准差 | 最差 |
| --- | ---: | ---: | ---: | ---: |
| log_mse | 0.379793 | 0.379738 | 0.000089 | 0.379808 |
| squared_rmsle | 0.379793 | 0.379725 | 0.000085 | 0.379793 |
| rmsle | 0.379780 | 0.379714 | 0.000078 | 0.379780 |

作为参照，原始三个单模型的算术平均是 **0.380398**、标准差 **0.000543**、
最差 **0.381149**。本次三个种子细化后都改善。联合候选仍只有一组三成员初值，
不能把三个成员当成三次独立的联合模型重复实验。

**冻结的选择是独立对数 MSE 平均**，审计为 **0.379348195**。三种独立平均的
检查分数差距不足 1e-5，按预先约定的顺序选择。后来更低的联合 RMSLE 审计分数
没有用来改写选择。所选输出通过相对旧冻结线性方案的 selection 晋级条件，
但没有提交新的 Kaggle 成绩；原始参考文件都保留。

21 个完整模型在 selection／审计的最终预测中均没有负的对数值，但这不代表
优化过程中的截断无关。冻结后的种子 43 重放发现一次线搜索试探有 **8,409 行**
为负，最小 **-4.718**；联合模型有 **5,243 行**，最小 **-4.188**。不截断和截断
损失在这些试探点确实不同，因此即使最终预测都为正，也可能经历不同的有限预算
优化路径。诊断重放保留了原先选中的迭代数，没有改变候选或晋级结果。

整轮记录用时 **116.15 秒**，RSS 峰值 **1200.9 MiB**，
包含数据检查、共享初值、全部细化、重复推理、保存产物及配对比较；不包含模块
导入、后续梯度轨迹／控制组诊断和回归测试。没有使用 GPU。

与 CI 命令一致的 CPU benchmark 回归全部通过：**200 项测试，219.47 秒**。
**26 个 CPU 模块共覆盖 3580／3580 条语句（100%）**，其中新增目标模块
**233／233**，没有排除行。这是上述模块的语句覆盖率，不是分支、GPU 或整个
代码库的覆盖率。测试覆盖联合梯度数值差分、平均后截断、完美预测、零步回退、
序列化、初值对照不被修改、先冻结再读取审计标签、产物／ID 校验和完整流程重放。
新模块及测试通过 Ruff 格式与关键错误检查；CI 已把本项测试及覆盖率目标加入原有
CPU benchmark 测试集合。

## 如何复现

按[上一轮同输入融合实验](FUSION_STRATEGIES.zh-CN.md)准备依赖和缓存，从仓库根目录执行：

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m benchmarks.mercari_objective \
  --data-dir benchmarks/runs/mercari/frontier-001/data \
  --manifest benchmarks/mercari/fusion-candidates.json \
  --anchor benchmarks/runs/mercari/fusion-strategies-001/verified/ensemble.npz \
  --output-dir benchmarks/runs/mercari/final-objective-reproduction
```

输出目录必须是新目录。不需要配置模型或损失参数，三种损失、种子、有限预算均已
预先固定。程序检查输入哈希和有序 ID，记录 `plan.json`；保存 `meta-models.pkl`
和 `meta-check.npz`，可独立核查策略检查分数；`models.pkl` 和带 ID 的预测档案
保存完整重训结果。`frozen.json` 先于审计标签，`report.json` 增加审计分数、种子
均值／标准差／最差值、联合与独立训练消融、条件配对区间和推理算术均值及全部样本。
预测模型只保存预处理和参数，不保存训练特征矩阵或标签；细化诊断应看包装器的
最终目标和历史，成员的 Adam 历史描述共享初值阶段。大模型、数据和凭据不进 Git。

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m pytest \

  --cov-report=term-missing --cov-fail-under=100
```

## 结论边界与来源

RMSLE 与平方 RMSLE 即使包含截断，也有相同的无正则最优解。有限预算下的梯度
缩放、线搜索和非凸网络仍可能产生不同轨迹。细化后的改善应与同优化器的对数
MSE 对照比较，不能只和之前 Adam 的结果比较。联合训练改变的是损失作用的位置，
没有解冻上游文本模型。

selection／审计复用、历史候选选择和反复查看会限制泛化结论。配对按行 bootstrap
只针对已拟合模型，不包含训练／选择不确定性，也未按重复商品组重采样。
三个独立细化种子是三次单模型重复；联合平均只有一组三成员初始化。
本地结果不意味着新的榜单排名。

- Byrd、Lu、Nocedal 与 Zhu（1995），L-BFGS-B：
  [doi:10.1137/0916069](https://doi.org/10.1137/0916069)。
- Wolpert（1992），Stacked Generalization：
  [doi:10.1016/S0893-6080(05)80023-1](https://doi.org/10.1016/S0893-6080(05)80023-1)。
