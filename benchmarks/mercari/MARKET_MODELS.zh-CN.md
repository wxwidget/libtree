# 二手市场结构与融合前模型优化

[English](MARKET_MODELS.md) · [完整实测](market-models-results.json) · [最终损失融合实验](FINAL_OBJECTIVE.zh-CN.md)

## 非高斯分布到底带来什么问题

原始价格右偏、带长尾是事实，但**树模型和对数价格 MSE 并不要求价格服从高斯分布**。
令 `Y=log1p(price)`，则在平方对数误差下：

```text
argmin_a E[(Y-a)^2 | X] = E[Y | X]
price_prediction = expm1(max(E[Y | X], 0))
```

这个条件均值结论只要求二阶矩存在，不要求价格正态、残差正态或方差相同。
RMSLE 是整体平方对数误差的根号，无正则最优解相同。目标的边际分布和给定商品
信息之后的条件分布，是不同问题。

因此，本轮保留对数价格目标。给预测额外加 `variance/2` 一类对数正态还原补偿，
会转向美元算术均值；原始价格 Gamma／Tweedie、分位数预测或按真实价位平衡加权，
也会改变目标或样本总体。它们可以服务别的业务需求，但不能仅因右偏就拿来替代比赛指标。

## 基础训练数据的证据

下列统计来自全部 **1,186,026 条基础训练记录**，不使用审计标签。

| 统计量 | 原始价格 | log1p(price) |
| --- | ---: | ---: |
| 算术平均 | 26.729896 | 2.979128 |
| 标准差 | 38.613703 | 0.748730 |
| 偏度 | 11.499688 | 0.660284 |
| 超额峰度 | 289.084293 | 1.092553 |

价格 P90／P99／P99.9 为 **51／170／450 美元**，最大 **2009 美元**；
有 **699 条零价格记录**，品牌缺失 **42.66%**。对数变换显著缓解了边际右偏，
但这不等于假定或证明条件残差正态。

电子类中，标题命中简单 `case|cover|protector` 配件正则的 19,748 条记录均价
**13.43 美元**；未命中这些词及损坏正则的 78,115 条均价 **40.40 美元**。
这是近似词义分组，不是已核实整机、严格同款比较或配件折价的因果估计。
损坏标题组均价反而为 47.93 美元，进一步说明不能用未经调整的词语分组推断成色影响。

这支持“商品异质性明显、高价尾部稀疏”，没有证明某个参数化条件分布正确。
品类、品牌、成色、运费与价格的关联也不等于因果作用。当前没有图片、时间戳、
卖家历史、可信原始零售价、需求或成交速度，不能凭现有字段编造这些变量。

二手商品应比较同型号／代际、成色、容量／尺寸、整机或配件、是否只有包装以及
套装数量。价格目标仍是**整套商品的价格**，不能把所有套装按猜测数量除价。
标题／描述只提供近似线索，卖家声明、矛盾描述和数量解析均可能出错。

## 这一轮修改的是哪一层

固定原 `frontier_sparse512_binary_huber` 文本模型，它只在基础训练窗口拟合；
复用同样只在基础集拟合的 LSA 编码器。每个新预测头只接收**一个**模型预测及商品
特征，不接收其他模型或最终融合预测。

文本主干、最终融合模型和最终融合权重保持不变。本轮重训的是融合前预测头，
没有重训原稀疏网络。这与“给最终融合再调权重”不同，额外计算成本也单独报告。

| 对照 | 目标与输入 |
| --- | --- |
| 原始文本模型 | 已有单模型预测 |
| Plain L2 | 对数残差；LSA／元数据＋一个预测 |
| Legacy L2 | 同样目标，增加原词义属性 |
| Market L2 | 同样目标，进一步增加标题／描述市场线索 |
| Market Huber | 同样丰富输入，换成稳健损失作对照 |
| Market regime | 同样丰富输入，四状态软概率及区间条件均值 |
| Comparables L2 | Market 输入＋基础集相似商品平滑均值／支持度／离散度 |
| Comparables regime | 相同相似商品输入，使用四状态软预测 |

市场线索区分 `no cracks or scratches` 等损坏否定词，保留 `does not work` 等明确
失效短语；分别编码标题和描述中的配件、空包装、套装数量、GB／TB 容量及价格涂改
占位符。数量／容量有上限，未知数量按一计。它不是完整的语言否定解析器，也不把
这些线索当成已核实事实。原有词义特征同时保留，因此市场特征比较属于增量消融。

相似商品采用已有 `ProductStatistics`：标准化完整标题、无序身份词、标题前缀、
品牌／品类／成色、型号数字五组键，各提供对数均值、支持度与标准差，共 15 列。
所有标签统计只来自基础训练集，平滑强度 20，向品牌／品类父级回退；未知键不使用
查询记录的价格。该统计组件已有独立的防泄漏、未知键及层级回退测试。

分布预测头包含四个状态：零价、正价格 <10、10–<50、≥50 美元：

```text
p[k]   = P(状态=k | 可观测商品信息)
mu[k]  = E[log1p(price) | 可观测信息, 状态=k]
pred_y = sum(p[k] * mu[k])
```

零价状态均值为零。门控用**不加类别权重**的交叉熵，避免改变后验概率。正价预测头
学习各状态的对数均值，以 `n/(n+500)` 向基础均值收缩，并限制在该区间的对数边界。
状态样本不足 200 条时使用训练均值；未见状态概率为零。冻结的零步模型在完整重训时
不会自行长出额外树。推理无需真实价格，没有硬切分或按真实价位选择模型。
这不是高斯混合似然拟合，也不是 NGBoost 的实现。

## 实验划分和公平比较

- 保持原基础训练／calibration／selection／审计的分组划分。
- calibration 共 74,129 条，按商品分组、种子 809 划成训练 59,305 条和调优 14,824 条；
  所有预测头使用相同划分和模型种子 42。
- L2／Huber 最多 450 轮、31 叶、学习率 0.05、最小叶支持度 80、L2 正则 10，
  特征采样率 0.85。以最终截断 RMSLE 调优早停，耐心 40。
- 门控／条件均值最多各 180 轮、15 叶、最小支持度 80、L2 正则 20。门控以交叉熵、
  条件头以区间内平方对数误差早停，耐心 25。这些是联合输出的代理训练目标，
  不是端到端直接优化最终 RMSLE。
- 完整 calibration 用冻结轮数重训，selection 只选择预测头、不拟合；差距 ≤1e-5
  时优先列表中更早／更简单方案。全部重训和预测先冻结，再读取审计标签。
- 不做过采样、目标加权或零价删除。按真实价格分桶只用于事后诊断。
- 使用两个 CPU 线程，推理重复三次，记录算术均值、最大值、标准差和全部原始样本。
  推理计时覆盖三个评估窗口的预测头；LSA／市场特征构建另计。缓存文本主干的训练／
  推理以及原 LSA 拟合成本都不在这些增量计时里。
- 多个门控／条件头与一棵残差树的工作量不同，不能把相同轮数称为相同计算预算。

第一轮检查了原始五种头后，才追加相似商品视图；保留首轮源码与结果。
这是顺序研究，不是完全预注册的盲测。selection／审计窗口也已在历史实验中复用。
程序校验数据／源码／编码器哈希、基础模型来源及全部有序 ID，数据和大模型不进 Git。

下一步优先做排除查询商品组的同款检索，把更准确的型号／成色信息用于文本主干，
再按可观测字段验证局部模型。先核查零价格含义，再制定只作用于训练数据的政策。
若业务需要预测区间，可单独评估条件不确定性；不要把区间改进等同点预测 RMSLE
提升，也不要删除审计零价、按真实价格路由或强加对数正态美元均值补偿。


即使本轮成功，也只是**单条模型分支**改善，不是完整系统的 0.3793 新成绩。
是否改善最终系统，还需要重新验证互补性和服务成本。本轮不改最终融合、不提交 Kaggle。
仅使用一个模型种子；配对按行 bootstrap 只针对已拟合模型，不包含训练／选择不确定性，
也未按重复商品组重采样或对多次尝试校正。

按真实价格分组后出现“低价高估、高价低估”，对最优条件均值也可能发生；这本身
不证明存在可直接部署的分桶校正。后续的同款检索、局部专家和不确定性特征，应使用
可观测字段，并做分组验证／交叉拟合，不能在审计集上拟合修正。

## 如何复现

按[前序流程](FRONTIER.zh-CN.md)准备基础模型预测与基础集拟合的 LSA 编码器，
从仓库根目录执行：

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m benchmarks.mercari_market_study \
  --data-dir benchmarks/runs/mercari/frontier-001/data \
  --manifest benchmarks/mercari/fusion-candidates.json \
  --base-predictions benchmarks/runs/mercari/frontier-001/a100/joint/sparse512_binary_huber.npz \
  --encoder benchmarks/runs/mercari/frontier-001/trees/encoder.pkl \
  --output-dir benchmarks/runs/mercari/market-models-reproduction
```

不需要新增模型调参选项，输出目录必须是新目录。`plan.json` 在拟合前生成；
所有模型、相似商品统计和带有序 ID 的预测都会保存；`frozen.json` 先于审计读取；
`report.json` 包含全部分数、价位分桶、配对区间、冻结预算和资源测量。

另提供[七个新预测头的候选清单](market-head-candidates.json)，保留独立效果较差的
分布头，已通过现有融合加载器的哈希、有序 ID 和拟合阶段校验。该清单指向本轮本地
实测路径；在其他目录重跑后，应按新产物生成路径与哈希。可合并原清单和新候选，
按[同输入融合流程](FUSION_STRATEGIES.zh-CN.md)另做验证；不要覆盖历史 72 列清单，
也不能把本轮单分支改善当成已经验证的完整融合提升。

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m pytest \
  tests/test_mercari_market.py --cov=benchmarks.mercari_market \
  --cov=benchmarks.mercari_market_study --cov-report=term-missing --cov-fail-under=100
```

与 CI 命令一致的 CPU benchmark 回归全部通过：**213 项测试，208.18 秒**。
**28 个 CPU benchmark 模块共覆盖 3811／3811 条语句（100%）**，新增两个模块
**231／231**，没有排除行。这不是整个代码库、分支或 GPU 的覆盖率。
测试先于实现及相似商品扩展编写，覆盖真实小数据训练、否定／数量线索、对数均值
计算、缺失／稀有状态、冻结零步回退、序列化、有序 ID、来源校验及先冻结再读审计。
Ruff 格式与关键错误检查通过。全部八个总分和 72 个分桶结果，另用
`math.log1p`／`math.fsum` 与 `pandas.cut` 独立复算一致；七个序列化预测头在
不含目标价格的原始商品记录上重放一致，候选清单通过现有融合加载器。

## 理论与引用

- Gneiting（2011），[Making and Evaluating Point Forecasts](https://doi.org/10.1198/jasa.2011.r10138)：
  点预测应匹配评分规则；前述条件均值结论也可由平方误差直接展开证明。
- Jankiewicz 与 Lopuhin，[Mercari 冠军建模资料](https://github.com/pjankiewicz/mercari-solution/blob/master/presentation/5_modeling.tex)：
  包含分类转回归、Huber 和交互特征，也明确记录了 mixture-of-experts 的失败尝试。
- Micci-Barreca（2001），[高基数分类特征的目标平滑](https://doi.org/10.1145/507533.507538)：
  本项目按训练集同款键作独立的层级平滑适配，并非论文结果复现。
- [LightGBM 官方目标函数定义](https://github.com/microsoft/LightGBM/blob/master/docs/Parameters.rst)：
  L2、Huber、交叉熵、Gamma、Tweedie 的目标与适用任务不同。
- Duan 等（2020），[NGBoost](https://github.com/stanfordmlgroup/ngboost)：
  分布／区间预测是可单独评估的扩展，本轮没有安装或实测 NGBoost。

词义线索、单模型残差对照及四状态软预测为本项目的独立适配，不宣称复现论文或冠军成绩。
