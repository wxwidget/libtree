# 保留弱候选，再评估残差融合

[English](RESIDUAL_FUSION.md) · [原始结果](residual-fusion-results.json) · [稀疏模型实验](SPARSE_PENALTIES.zh-CN.md)

## 当前究竟怎样融合

当前是多层回归融合，学习的是 `z = log1p(price)`，没有使用多数投票：

1. 底层模型学习不同的文本表示和损失目标。
2. 部分校准分支学习底层预测的残差：
   `q(x) = b(x) + h(原始模型预测, 商品上下文)`。
3. 外层对冻结的最佳方案、原始模型和残差分支加权。实验支持非负且权重和为
   1 的线性融合、带截距且约束权重总量的融合、按大类收缩的条件融合。
   最后用 `expm1(max(z, 0))` 还原价格。

冻结的 0.380616 最佳方案外层是非负、权重和为 1 的线性融合，多个内部
分支包含树残差校正。本次新增的正负系数位于**内部残差线性模型**，外层
仍保留非负约束。外层只决定整体贡献，内部树可以在不同商品区域使用弱候选。

冻结最佳方案外层五个有效权重为：旧完整融合 38.4579%、CPU 多尺度 4.8394%、
商品校准 LibTree 深度 5 为 26.5906%、商品校准 LightGBM 为 20.0964%、
商品校准 XGBoost 为 10.0157%。它们加权的是**对数价格预测**。

## 为什么弱模型值得保留

平方误差下，当前预测的负梯度就是 `r = z - prediction`。Gradient boosting
学习能解释这个残差的函数，然后用学习率缩小更新幅度。单独 RMSLE 较差的
模型，仍可能带有关于这个残差的信息，或者只在某些品类特别有用。因此单模型
排名不能直接决定它对融合是否有用。

但把几个独立训练的弱模型平均，并不自动满足 boosting 的理论条件。误差高度
相关、预测无关、过拟合都可能带来退化。要衡量它对当前模型的条件贡献，也允许
最终权重为零。

需要澄清：上一轮六个候选其实全部保留，包括未达到收敛条件的 Lasso、
Elastic Net；是最终线性融合给了它们零权重。本次扩展的是后续融合能力，
让它们还能进入残差模型，而不是把此前不存在的单模型淘汰门槛说成已经删除。

## 本次实现

- 有限数值、ID 对齐的原始模型全部留下。独立分数、收敛警告、直接权重为零
  都不触发提前淘汰；数据错误仍直接报错。
- 内层参考是 calibration 上平方误差最小的原始模型。新增两条并行候选：
  标准化后的正负系数 Ridge 残差校正（alpha 固定为 100）；LibTree GBDT
  残差校正（300 棵树、深度 4、学习率 .04、128 bins、叶子至少 100、L2 20）。
  两个分支都不按独立分数提前筛选。
- 输入包括参考预测、所有候选相对参考的差值、仅在 base 训练集拟合的商品
  统计量、无标签文本属性。直接融合权重为零仍可通过残差分支发挥作用。
- 两条校正分支只用 calibration 标签训练。树不使用刚拟合的 Ridge 的训练内
  残差；树自身内部才是逐轮的 gradient boosting。
- 最强冻结方案已经见过 calibration 标签，不能再作为这一层的训练特征或
  残差目标。它只参加外层融合，避免标签泄漏。
- 去掉 Lasso／Elastic Net 的消融，会重新训练不含对应模型的两条校正分支，
  同时去掉直接和间接作用。另设仅直接融合的 raw-only 对照。
- 最终仍要求 selection 的分组半窗口上至少提升 1e-5 RMSLE。若未通过，输出
  与原方案逐位一致。候选保留与最终晋级是两个不同阶段。

参数均为内部固定默认值，不需要增加模型参数配置。

## 如何复现

先按[稀疏模型实验](SPARSE_PENALTIES.zh-CN.md)准备分组的 80/5/5/10 数据窗口
及六个可信的 base-only 模型产物。安装 Mercari 依赖后执行：

```bash
OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 python -m benchmarks.mercari_residual \
  --data-dir benchmarks/runs/mercari/frontier-001/data \
  --anchor benchmarks/runs/mercari/smalltext-t4-001/primary-blend/ensemble.npz \
  --experts-dir benchmarks/runs/mercari/sparse-penalties-001/implicit \
  --output-dir benchmarks/runs/mercari/residual-retention-reproduction
```

输出目录必须是新目录。程序检查原实验的数据哈希、三个预测窗口的有序 ID、
预测长度和有限性，记录源码及输入哈希，保存八个校正模型、上下文统计量、
预测和外层权重。在读取审计标签前写入 `frozen.json` 并确定晋级结果。
复用底层模型的训练与预测成本不计入本次增量耗时。

重新运行 `python -m benchmarks.mercari_top3 ...` 时，六个原始模型训练完成后
也会自动执行同一阶段。大数据、模型和密钥不进入 Git；前置产物的重建步骤
见链接中的稀疏模型及小文本实验报告。

原始词对 Ridge 的审计 RMSLE 为 **0.472611**。全部六个候选的残差树为
**0.449182**，优于仅使用四个 Ridge 的 **0.451688**，在这个稀疏模型分支内
相对降低 **0.555%**。去掉 Lasso 略有帮助，去掉 Elastic Net 则变差，
因此不能说两个模型在每种组合里都带来收益。

完整残差树在 Lasso 差值上分裂 **76** 次，在 Elastic Net
差值上分裂 **218** 次，共 **3864** 个内部节点。
线性残差模型还分别使用 **0.601941**、
**-1.208014** 的未标准化差值系数。这证明候选确实被使用；
分裂次数和系数都不是因果重要性，相关预测还可能使系数不稳定。

**最终没有晋级。** 仅直接融合与新增残差分支的外层融合，都选择保留原方案，
新增分支权重接近零。重新拟合的单 anchor 截距得到 **0.380616369**，还略差于
原始 **0.380616255**；最终 selection 检查拒绝该提案。输出的三个窗口预测数组
与原方案**逐位一致**，最大差为 0。未产生新的 Kaggle 提交或成绩。

整轮计时 **78.05 秒**，进程 RSS 峰值 **2592.4 MiB**。
计时包含数据／哈希检查、上下文特征、八个模型、重复推理和外层拟合，停止于最终
bootstrap 与输出写入之前；不包含复用的底层训练和预测。上面的模型使用统计是
冻结后的解释性诊断，没有用来改变晋级选择。

完整 CPU 优化回归 **175 项测试通过**，耗时 **212.50 秒**；覆盖 24 个模块的
**3,126/3,126 条语句（100%）**，新增残差模块为 125/125。这里指该测试范围内的
语句覆盖，不代表全仓库、分支或 GPU 覆盖率。TDD 保留了模块缺失的初始失败记录，
并验证了弱模型正负互补、条件树学习、序列化精确重放、家族排除、anchor 隔离、
有限数值／ID／哈希校验、先冻结后审计和精确回退。测试输出另有 492 条既有警告。

启用实际 JIT 路径的专项回归也已通过：**17 项，4.49 秒**。
