LibTree 性能、竞品对比与测试报告
================================

生成时间：2026-10-09
平台：Linux x86-64，AMD EPYC 9V74，GCC 14.2，Python 3.12
引擎：LibTree、XGBoost 3.4.1、LightGBM 4.7.0

一、结论
--------

1. 在当前固定参数和云环境中，LibTree 的 C++ 版本五个数据集的中位训练时间为
   5.365 ms，XGBoost 为 15.568 ms，LightGBM 为 10.571 ms；对应约快 2.90x 和
   1.97x。
2. C++ 推理中位时间为 LibTree 0.180 ms、XGBoost 0.427 ms、LightGBM 0.912 ms；
   LibTree 约快 2.37x 和 5.07x。
3. Python 接口的模型效果与 C++ 完全一致。五个数据集的中位训练时间为
   LibTree 5.632 ms、XGBoost 22.178 ms、LightGBM 22.408 ms；推理为
   0.240 ms、1.261 ms、1.576 ms。
4. LibTree 在这组固定参数下的效果并非所有数据集都第一：保险数据的 XGBoost
   R² 略高；Telco 的 ROC-AUC 基本相同。Wine、Pima、Titanic 的主指标由 LibTree
   取得最高值。
5. 多线程测试覆盖 1/2/4 线程、7 个数据集、两种接口、3 个随机种子和 3 次计时，
   共 1,134 条原始测量。小数据集受调度开销影响，Friedman 大数据集收益最明显。

五、测试方法与限制
------------------

所有竞品使用相同数据划分、随机种子 42/2024/2026 和固定参数：100 棵树、深度
4、64 分箱、学习率 0.1、L2=1、最小叶样本数 5。优化对比使用每个划分 5 次计时；
多线程对比使用每个划分 3 次计时。计时包含训练所需的矩阵/分箱处理，不包含下载和
进程启动；推理包含接口校验和必要转换。

Kaggle API 在当前网络环境被代理以 HTTP 403 拒绝，因此使用固定 SHA256 的公开镜像，
不能宣称官方 Kaggle 字节级身份或 Kaggle 排行榜成绩。结果是当前硬件、数据和参数
下的可复现实验，不代表所有规模、平台、GPU、稀疏数据或超参数搜索场景的普遍排名。
