LibTree benchmark report
Measured: 2026-10-10
Machine: AMD EPYC 9V74, 4-core cgroup CPU quota, GCC 14.2, Python 3.12
Competitors: XGBoost 3.4.1 and LightGBM 4.7.0

Scope
-----
Insurance, Bank Marketing, Friedman 20k, and Friedman 100k; C++ and Python
interfaces; LibTree, XGBoost, and LightGBM; 1, 2, and 4 threads; three seeds;
three fresh-process timing repeats per seed. The raw file contains 648 timing
records, each with fit and prediction times. They are reported separately.

Four-thread training scaling
----------------------------
Scaling factor = arithmetic mean fit time at one thread / arithmetic mean fit
time at four threads. Medium/large mean is the arithmetic mean across Bank
Marketing, Friedman 20k, and Friedman 100k.

Assessment
----------
The stated requirement that LibTree's training scaling exceed both competitors
is not met. LibTree exceeds XGBoost on the medium/large workloads, but LightGBM
scales faster in both interfaces. The current code changes reduced LibTree's
four-thread mean fit time by about 12.6%-20.5% versus the archived measurements
on the same workloads and seeds. Those before/after timings are directional:
the benchmark order changed and cloud scheduling is variable. The full report
does not hide slow cases or summarize times with medians.

Changes measured
----------------
1. Reuse split-search left/right gradient, Hessian, and row-count totals rather
   than rescanning child rows to recompute them.
2. Compute per-row gradients and losses in fixed-size chunks with a fixed
   reduction order, enabling deterministic parallel work.
3. Preserve adaptive layer scheduling for sufficiently large tree workloads.

An attempted parallel partition and a flattened node-feature histogram queue
did not improve the measured scaling and were removed.

Validation
----------
CTest 5/5; Python 31/31; CLI 13/13; performance and memory 2/2; benchmark tests
5/5. C++ line coverage 1349/1349 (100%); Python 148/148 (100%). ASan, UBSan,
LSan, and ThreadSanitizer passed.

Reproduce
---------
python -m pip install -r benchmarks/requirements.txt
make all
PYTHONPATH=python python benchmarks/parallel.py \
  --datasets insurance bank_marketing friedman_20k friedman_100k \
  --threads 1 2 4 --seeds 42 2024 2026 --repeats 3 \
  --output benchmarks/parallel-results.json
python -m pip install -r benchmarks/requirements-report.txt
python benchmarks/parallel_report.py --input benchmarks/parallel-results.json

Full details and raw values are in PARALLEL_REPORT.zh-CN.md,
parallel-results.json, and parallel-summary.json.
