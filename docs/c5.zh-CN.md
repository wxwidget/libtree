# C5 风格分类：从规则读懂预测

[English](c5.md) · [交互规则指南](C5_GUIDE.html) ·
[实测与消融](../benchmarks/C5_REPORT.zh-CN.md)

新增独立的 `C5Classifier`：二分类/多分类、样本权重、SAMME boosting、剪枝、
gain ratio/entropy/gini 三种准则，以及忠实于预测的 IF–THEN 规则。
这是 C5 风格实现，未移植 C5.0 源代码，不兼容其模型文件、置信因子剪枝、
类别子集划分、winnowing 或规则优化。具体方法和引用见[英文指南](c5.md)。

## 从一个例子开始

```python
import numpy as np
from libtree import C5Classifier

# 余额、逾期天数；这是教学数据，不是金融效果评估。
x = np.array([[500, 0], [100, 1], [200, 2],
              [500, 20], [100, 25], [200, 15]], dtype=np.float32)
y = np.array(["repays", "repays", "repays", "late", "late", "late"])
with C5Classifier(n_estimators=5, max_depth=3, min_samples_leaf=1) as model:
    model.fit(x, y)
    print(model.classes_)  # late=0，repays=1
    print(model.dump_rules(feature_names=["余额", "逾期天数"]))
    print(model.explain([200, 15], ["余额", "逾期天数"], format="text"))
    explanation = model.explain([200, 15])
    assert explanation["predicted_label"] == model.predict([[200, 15]])[0]
```

树会按逾期天数是否大于 2 分成两类。纯净第一棵树会提前结束 boosting。
该例中 NaN 进入左侧偿还分支：缺失方向由训练决定，相同得分时选左侧。
Python 的类别按 `classes_` 排序映射，文本/JSON 附带标签列表；JSON 单条解释
有 `predicted_label`。原生 C++ 使用类别整数索引。

X 是二维数值矩阵，y 是一维标签；Python 支持有限数值或字符串，最多 256 类。
单类别数据产生常量模型。NaN 表示缺失，无穷值拒绝输入。类别特征先用训练集
拟合编码器；预测保持相同列顺序，测试集不参与拟合或调参。

## 理解方法

决策树不断询问“是否小于等于阈值”，叶子选择加权数量最多的类别。
`sample_weight=` 表示样本的重要程度。Boosting 顺序训练多棵树，提高误分
样本的权重。K 类 SAMME 的树票数为：

```text
vote = learning_rate × [log((1-error)/error) + log(K-1)]
误分样本权重乘 exp(vote)，全部权重再归一化到总和 1
```

树必须好于随机分类，error < 1-1/K。后续不合格树丢弃并结束训练；第一棵
不合格时保留多数类模型。完美树提前结束，误差截断到 1e-15 保持票数有限。
单类别模型票数为 1；最终票数相同时选较小的类别索引。树数 1 关闭 boosting。
`estimator_errors_` 是每棵树当轮加权误差，不是整个模型的最终误差。

剪枝自底向上比较子树与叶子，最小化“全局归一化加权训练误分类误差 +
alpha × 叶子数”。alpha=0 关闭后剪枝，更大值偏好更简单的树。该方法采用
成本复杂度原则，不是 C5.0 置信因子剪枝。sklearn ccp_alpha 用 impurity，
同数值不表示同强度。应在验证集选 alpha，最终测试集只评估。

| 准则 | 含义 |
| --- | --- |
| gain_ratio | 信息增益除以划分信息量；默认，过滤低增益候选 |
| entropy | 直接减少类别不确定性 |
| gini | 降低混杂度，无需对数运算 |
| hellinger | 二分类条件分布距离；见[风险优化方法](c5-risk.zh-CN.md) |

信息熵为 `-sum(p log2 p)`；Gini 为 `1-sum(p²)`。gain ratio 每个特征取
最优比率候选，再要求信息增益不低于有效特征候选平均增益。这是直方图近似，
没有实现原版 C4.5 所有连续阈值/MDL 修正。三种准则都有同配置消融。

## 规则如何复现预测

每个保留叶子变为一条规则，重复特征条件合并成 `下界 < x <= 上界`，是否接受
缺失单独记录。每棵树恰好命中一条规则，按类别加总票数，最大者为预测。
它不是另拟合的解释器、SHAP 或因果证明。

`dump_rules('json')` 返回 JSON 字符串；`explain(sample)` 返回字典。
schema_version=1；规则有 ID、树索引、条件、support、weighted_purity、vote。
support 计训练行数，包括零权重样本；纯度是该轮叶子的多数类权重占比，不是
未来准确率；vote 属于整棵树，不是叶子概率。单条解释展示实际观察值、命中
规则、各类累计票数，NaN 为 JSON null。文本阈值保留 float32 可往返精度，
纯度/票数为四位有效数字；JSON 保留 double 完整精度。

`predict_proba` 是 `softmax(votes/sum(votes))`，与解释中的概率一致。
这个保守映射未经校准，不等同于 sklearn SAMME 概率或 C5.0 置信度；二分类
上限约 .731，即使训练树完全正确也一样。分别评估准确率、AUC 和校准；
需要校准概率时用独立验证集。规则数/条件数只是可读性代理，尚无人类理解实验。

## 参数、性能与生命周期

默认 10 树、深度 6、64 bins、叶子至少 5 行、学习率 1、alpha=.001、
min_gain=1e-9、gain ratio、1 线程。深度 0 可用，最大 32；bins 最大 256、
树数最大 1000、线程最大 256。输入校验上限 1 亿行/10 万特征不是内存容量承诺。

训练集未加权全局分位阈值只计算一次，uint16 列式 bins 在各轮复用；直方图
使用当轮权重。足够大的训练 `行数×特征>=65536` 建池并行处理特征，依赖节点
和 boosting 轮次仍串行。有池且 `预测行数×已接受树数>=65536` 才并行预测。
小任务串行，固定归约顺序确保 1/4 线程逐位相同。预测复用每个 worker 的
票数缓冲区，剪枝后压紧存储。连续 float32 输入可避免转换副本。

set_params 在下一次 fit 生效；失败 fit 保留旧模型，with/close 释放线程和内存。
允许并发只读，禁止与读取并发 fit/close。本版不提供 C5 持久化/原生类别划分，
规则 JSON 是检查格式。已有 GBDT 接口和 xgbt 持久化独立使用。

## C++ 与命令行

C++ 类型定义在 libtree/c5.h，提供 Fit、Predict、PredictProba、rules、DumpRules、
Explain；完整示例和 LtC5* C ABI 缓冲契约见[英文指南](c5.md#c-and-c-abi)。
输入只借用到调用结束，C5 handle 不能混用 GBDT 操作。

```sh
PYTHONPATH=python python -m libtree rules --train labeled.csv --header \
  --rounds 10 --depth 4 --criterion gain_ratio --alpha .001 --threads 4 \
  --feature-names balance,days_late --format text > rules.txt
PYTHONPATH=python python -m libtree explain --train labeled.csv --header \
  --sample 200,15 --feature-names balance,days_late --format json
python -m libtree --help
```

CSV 第一列为数值标签，每条命令训练新模型；Python API 也可用字符串标签。
样本可用 nan；还可设置 --min-leaf、--bins、--rate、--min-gain。
竞品比较复现、原始重复运行、平均数/标准差/极值和消融见实验报告。
